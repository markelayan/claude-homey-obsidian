## Who runs it
Agent `illustrator`, then the main session lists it and looks at it.

## Steps
1. Load `json-canvas`. Copy the template from `System/Templates/`. Write the file directly.
2. Keep cards short, with `file` cards pointing at notes for detail.
3. Report the path. The main session lists it under `## Canvases` in `Home.md`, with the user's approval, and takes a screenshot. A canvas embedded in a note shows empty boxes, so never embed one.

## Rules
Fill `summary` with one line. Use `[[wikilinks]]`. No H1: Obsidian shows the name as the title. Do not touch `Daily/` or `Home.md`, and do not set goals or change plans: only the user does. Report one line: what you did, the note path, anything unknown. Do not guess; write `unknown`.

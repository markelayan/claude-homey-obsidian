# Homey - Obsidian Orchestrator

Long-term memory and agent orchestration for Claude Code, kept in an Obsidian vault you can read. A lead session remembers across sessions, hands work to cheap agents through task notes, checks their results, and brings you only the decisions.

It needs macOS, Obsidian 1.14 or later with its command line on, and Python 3. Setup, the flow, daily use and warnings are in the [full README](https://github.com/markelayan/claude-homey-obsidian#readme).
